# 기술 심화·학습 노트 (tech-notes)

구현을 통해 익힌 기술을 **왜/어떻게 관점으로 깊이 정리한 커밋 대상 문서**를 모으는 폴더다.
"무엇을 만들었나"에 더해 **다음에 혼자 쓰기 위한 개념 학습 로드맵과 사용 시 주의점**까지 담는다.

## 다른 문서와의 경계

| 폴더/파일 | 성격 | tech-notes와의 차이 |
|---|---|---|
| `docs/architecture.md` 등 루트 | 현행 시스템 기술 문서 | "지금 시스템이 어떻게 생겼나" (상태) |
| `docs/features/` | 기능별 설계 문서 | 특정 기능의 설계·동작 (상태) |
| `docs/improvements/` | 개선 계획 | "무엇을 왜 바꿀 것인가" (계획) |
| `docs/logs/` | 개발 일지 | 세션별 서술형 작업 기록 (시간순) |
| **`docs/tech-notes/`** | **기술 학습 노트** | **구현에서 익힌 개념·주의점의 재사용 가능한 정리 (학습)** |
| 루트 `notes/` (gitignore) | 개인 스크래치 메모 | 커밋하지 않는 개인 메모 — tech-notes와 **다름** |

> ⚠️ 커밋하는 기술 학습 문서는 여기(`tech-notes/`)에, 커밋하지 않는 개인 메모는
> `.gitignore`로 제외되는 루트 `notes/`에 둔다. 이름이 비슷하니 혼동하지 말 것.
