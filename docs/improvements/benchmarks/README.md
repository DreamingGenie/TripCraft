# 성능 벤치마크 결과

[개선 02](../02-bulk-place-data.md) §4의 측정 프로토콜에 따라 수집한 **최적화 전/후 성능 수치**를 누적하는 폴더.

## 파일 규칙

- `YYYY-MM-DD_<시나리오>.md` 또는 `.csv` — 측정 1회분.
- 각 측정에는 다음을 함께 기록한다:
  - 데이터셋 규모(행 수), 측정 환경(로컬/도커, MySQL 버전)
  - 쿼리 원문 + `EXPLAIN` 출력
  - 반복 횟수, p50/p95(ms) 또는 처리량(건/초)
  - 적용한 최적화(Before / Level 1 / Level 2 / Level 3)와 재현 스크립트 경로

> baseline("before")을 반드시 최적화 이전에 먼저 기록할 것 — 개선 폭은 before가 있어야 의미가 있다.
